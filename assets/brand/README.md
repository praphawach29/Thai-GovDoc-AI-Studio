# Thai GovDoc AI Studio — logo

- `thai-govdoc-logo.svg` — primary horizontal lockup, transparent background
- `thai-govdoc-icon.svg` — square mark for app icon and compact placements
- `thai-govdoc-logo-mono.svg` — single-colour lockup

Palette: deep teal `#153944`, jade `#83D2BD`, warm amber `#F1B95B`. The mark pairs an official document silhouette and drafting lines with a small AI glint. It does not use the Garuda, which remains reserved for official document layouts.

SVG wordmark uses system Thai sans fonts (`TH Sarabun New`, `TH SarabunPSK`, Noto Sans Thai, Tahoma). For consistent print production, convert the wordmark to outlines in a vector editor with the intended font installed.
